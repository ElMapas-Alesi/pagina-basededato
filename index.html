FUNDAMENTOS

¿Qué es SQL?

SQL (Structured Query Language) es un lenguaje utilizado para administrar y manipular bases de datos relacionales.

Permite crear estructuras, insertar información, modificar registros, eliminar datos y realizar consultas para obtener información específica.

SQL es utilizado por sistemas y aplicaciones que necesitan almacenar grandes cantidades de información de forma organizada.

ESTRUCTURA

Tablas

Las tablas son la estructura principal donde se almacena la información de una base de datos relacional.

Cada tabla está formada por columnas y filas.

  • Las columnas representan atributos.
  • Las filas representan registros.
  • Cada columna tiene un tipo de dato.

ORGANIZACIÓN DE DATOS

Normalización

La normalización es un proceso utilizado para organizar los datos de una base de datos y reducir la redundancia o repetición innecesaria.

Su objetivo es conseguir una estructura más eficiente, coherente y fácil de mantener.

1FN

Primera Forma Normal

Cada campo debe contener un único valor y no debe haber grupos repetitivos.

2FN

Segunda Forma Normal

Debe cumplir 1FN y los atributos deben depender completamente de la clave primaria.

3FN

Tercera Forma Normal

Debe cumplir 2FN y no deben existir dependencias transitivas.

MANIPULACIÓN DE DATOS

Consultas SQL

SELECT

Consultar información

Permite obtener datos de una o varias tablas. 

SELECT *
FROM usuarios;
WHERE

Filtrar resultados

Permite establecer condiciones. 

SELECT *
FROM usuarios
WHERE edad > 18;
INSERT

Insertar datos

Agrega nuevos registros a una tabla. 

INSERT INTO usuarios
(nombre, edad)
VALUES
('Juan', 20);
UPDATE

Actualizar datos

Modifica información existente. 

UPDATE usuarios
SET edad = 21
WHERE id = 1;
DELETE

Eliminar datos

Elimina registros de una tabla. 

DELETE FROM usuarios
WHERE id = 1;
JOIN

Combinar tablas

Permite relacionar información entre tablas. 

SELECT *
FROM clientes c
JOIN pedidos p
ON
c.id = p.id_cliente;

PROGRAMACIÓN SQL

Stored Procedures

Un Stored Procedure es un conjunto de instrucciones SQL almacenadas dentro del servidor de la base de datos.

Puede recibir parámetros, realizar operaciones y devolver resultados.

Son útiles para reutilizar código y centralizar operaciones frecuentes sobre los datos. 

DELIMITER //

CREATE PROCEDURE
buscar_usuario(
    IN usuario_id INT
)

BEGIN

    SELECT *
    FROM usuarios
    WHERE
    id = usuario_id;

END //

DELIMITER ;
